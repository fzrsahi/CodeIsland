Built for Flow. Engineered for Speed.

Morrow replaces distracting floating HUDs with hardware-level integration.

⚡

100% Native Swift & Rust

Zero Electron overhead. Idles at under 1% CPU and less than 35MB RAM. Won't drain your MacBook battery during all-day coding sprints.

🎵

Sub-Notch Synced Lyrics

Smooth floating subtitle pill anchored directly underneath the physical camera cutout. Zero horizontal marquee scrolling, driven by spring physics.

🤖

AI Agent Telemetry

Direct telemetry integration for Claude Code, Codex, Cursor, and Gemini CLI. Inspect running commands and token velocity with a single hover.

🌐

Multiplatform Monorepo

Designed natively for macOS Sonoma/Sequoia, with official companion builds for Windows and Linux desktops in the same unified release.

Ready in Seconds

Get Morrow running in three painless steps.

01

Download Installer

Grab the latest .dmg (macOS), .exe (Windows), or .AppImage (Linux) from GitHub Releases.

02

Install & Launch

Drag Morrow to your /Applications folder. On first launch, grant Accessibility permissions for notch HUD overlay.

03

Enjoy the Notch

Morrow tucks itself into your top notch automatically. Start your music or coding agents to see it come to life.

Build from Source (Terminal) 
git clone https://github.com/fzrsahi/Morrow.git
cd Morrow && swift build -c release
open .build/release/Morrow.app
